Excel do Zero: curso de Excel grátis para quem nunca abriu o Excel

Aprenda Excel do primeiro clique, com aulas curtas, uma tela que imita o Excel de verdade e correção que explica cada erro. Sem cadastro e sem pagar nada.

📚 5 aulas⏱️ ~49 min🎯 Iniciante🌐 Português
Grátis
Começar o curso
  • ✔ Aulas interativas no navegador
  • ✔ Exercícios com correção
  • ✔ Mini projetos no Excel de verdade
  • ✔ Sem cadastro

O que você vai aprender

  • O que é o Excel e quando ele é (ou não é) a ferramenta certa
  • Arquivo e abas: criar, renomear e organizar
  • As partes da tela: Faixa de Opções, Caixa de Nome, Barra de Fórmulas e barra de status
  • Salvar no Excel online e no instalado (Ctrl+B)
  • Quando usar .xlsx, .csv e .pdf
  • Criar e baixar o seu primeiro arquivo no Excel de verdade

Conteúdo do curso

Novos módulos entram aqui assim que ficam prontos.

Módulo 0 · Conhecendo o Excel5 aulas · ~49 min

O primeiro contato: o que é o Excel, como ele organiza os dados, as partes da tela e como salvar o seu trabalho.

Para quem é

  • Quem nunca abriu o Excel ou abre com medo
  • Quem precisa de Excel para conseguir ou manter um emprego
  • Quem quer começar o caminho para trabalhar com dados

Requisitos

  • Nenhum conhecimento prévio
  • Um computador com internet (o celular serve para assistir às aulas)
  • Uma conta Microsoft gratuita, para praticar no Excel online

Como funciona cada aula

1 · Aprenda

Veja passo a passo

Uma animação mostra cada passo numa tela que imita o Excel, com explicação em texto.

2 · Pratique junto

Com a tela te guiando

Você clica e digita. Se errar, a tela explica o motivo e dá dicas.

3 · Sozinho

Desafio sem ajuda

Um problema novo, sem destaque, para você provar que aprendeu.

4 · Resumo

O que levar daqui

As ideias-chave, os erros comuns, um atalho e como fazer no Excel de verdade.
